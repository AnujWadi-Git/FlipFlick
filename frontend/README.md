# FlipFlick — frontend

Next.js (App Router) + TypeScript + Tailwind CSS v4 + Framer Motion.

See the [project root README](../README.md) for the full architecture writeup, the ML pipeline explanation, and setup instructions. Quick start:

```bash
npm install
cp .env.local.example .env.local   # point at your backend (defaults to localhost:8000)
npm run dev
```
